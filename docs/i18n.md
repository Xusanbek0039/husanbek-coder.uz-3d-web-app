# Ko'p tillilik (uz / ru / en)

Sayt `next-intl` asosida 3 tilda ishlaydi:

| Til | URL | Misol |
|---|---|---|
| O'zbekcha (asosiy) | prefikssiz | `/about` |
| Ruscha | `/ru` | `/ru/about` |
| Inglizcha | `/en` | `/en/about` |

`/uz/...` manzillari avtomatik prefikssiz versiyaga yo'naltiriladi.

## Qayerda nima

- `messages/{uz,ru,en}.json` — barcha UI matnlari. Yangi matn qo'shsangiz, **uchala** faylga ham bir xil kalit bilan yozing.
- `src/data/projects-i18n.ts` — loyihalarning ru/en sarlavha, kategoriya va qisqa tavsifi.
  Loyihaning batafsil `content` qismi (`src/data/projects.tsx`) hozircha faqat o'zbekcha — ru/en sahifalarda shu haqda eslatma chiqadi.
- `src/data/services.ts` — xizmatlar, jarayon, FAQ va byudjet variantlari (`{ uz, ru, en }` ko'rinishida).
- `src/i18n/routing.ts` — tillar ro'yxati va standart til.
- `src/middleware.ts` — til prefiksini aniqlaydi.

## Komponentda ishlatish

```tsx
// client komponent
import { useTranslations } from "next-intl";
const t = useTranslations("hero");
t("greeting");

// server komponent / sahifa
import { getTranslations } from "next-intl/server";
const t = await getTranslations("about");
```

Ichki havolalar uchun `next/link` emas, `@/i18n/navigation` dagi `Link` ishlating — u joriy til prefiksini o'zi qo'shadi:

```tsx
import { Link } from "@/i18n/navigation";
<Link href="/services">...</Link>   // ru sahifada -> /ru/services
```

Tashqi havolalar (`https://...`) va `#hash` havolalar uchun oddiy `<a>` yoki `next/link` yetarli.

## Yangi sahifa qo'shish

1. Sahifani `src/app/[locale]/<yo'l>/page.tsx` ga yarating.
2. Boshida `setRequestLocale(params.locale)` chaqiring (statik generatsiya uchun).
3. `generateMetadata` da `alternatesFor(locale, "/<yo'l>")` bilan canonical va hreflang qo'ying.
4. `src/app/sitemap.ts` ga `entry("/<yo'l>", ...)` qo'shing.
